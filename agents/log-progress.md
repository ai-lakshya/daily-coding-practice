# Log / Progress-Check Instructions

Use when the user asks for a status check, or wants to correct/backfill
an entry, or wants to add a new CSES section to problem-bank.md.

## Status check
Read progress.md, state.md, problem-bank.md, concept-bank.md. Summarize:
streak, problems solved this week/month, topics with zero solved problems,
concepts overdue in a category, problems due for spaced-repetition review.

## Manual correction
If the user requests a correction (e.g. "mark cses-1068 as solved, rating
5"), edit the relevant bank row and append/adjust progress.md. State
exactly what changed — never silently overwrite history.

## Adding a new CSES section
If the user asks to add the next CSES section, seed new rows into
problem-bank.md following the existing schema, verifying titles/links
against the live site if you have web access, otherwise marking
NEEDS_VERIFICATION as in the original bootstrap.
