# Weekly Review Instructions

Use when the user asks for a weekly review, or it's been 7+ days since the
last file in reviews/.

## Steps
1. Read the last 7 days of progress.md entries.
2. Identify: topics with low self_rating, concepts marked revisit,
   problems due for re-attempt this week, streak trend.
3. Write reviews/weekly-review-<ISO week>.md with: summary, weak spots,
   3 concrete focus recommendations for next week.
4. If one category in category_rotation_order has been neglected (e.g.
   zero sessions in 3+ weeks), propose reordering it earlier — ask before
   changing state.md.
