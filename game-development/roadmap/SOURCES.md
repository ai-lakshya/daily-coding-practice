# Master Bibliography

Every source cited anywhere in this roadmap, by short key. Theory units
cite these keys plus a specific chapter/section — never a bare book name.

`FREE` marks sources that are legally free online.

---

## Core books — the spine

| key | source |
|---|---|
| `[GEA3]` | Jason Gregory, **Game Engine Architecture**, 3rd ed. (2018). The single most useful book on this list. Read it in slices alongside the topics, not front-to-back. |
| `[GPP]` | Robert Nystrom, **Game Programming Patterns**. `FREE` — https://gameprogrammingpatterns.com/contents.html |
| `[RTR4]` | Akenine-Möller, Haines, Hoffman et al., **Real-Time Rendering**, 4th ed. (2018). The reference for T04/T08. Companion site with free chapters: https://www.realtimerendering.com/ |
| `[RTCD]` | Christer Ericson, **Real-Time Collision Detection** (2004). The physics/collision reference. Nothing has replaced it. |
| `[FGED1]` | Eric Lengyel, **Foundations of Game Engine Development, Vol. 1: Mathematics** (2016). |
| `[FGED2]` | Eric Lengyel, **Foundations of Game Engine Development, Vol. 2: Rendering** (2019). |
| `[3DMP]` | Dunn & Parberry, **3D Math Primer for Graphics and Game Development**, 2nd ed. `FREE` — https://gamemath.com/book/ |
| `[GPED]` | Ian Millington, **Game Physics Engine Development**, 2nd ed. (2010). Builds a physics engine end-to-end; the pedagogical counterpart to `[RTCD]`. |
| `[AIFG]` | Ian Millington, **AI for Games**, 3rd ed. (2019). |
| `[PBRT]` | Pharr, Jakob, Humphreys, **Physically Based Rendering**, 4th ed. `FREE` — https://pbr-book.org/4ed/contents |
| `[DOD]` | Richard Fabian, **Data-Oriented Design**. `FREE` — https://www.dataorienteddesign.com/dodbook/ |
| `[GAMEFEEL]` | Steve Swink, **Game Feel: A Game Designer's Guide to Virtual Sensation** (2008). |
| `[LENSES]` | Jesse Schell, **The Art of Game Design: A Book of Lenses**, 3rd ed. (2019). |
| `[CCIA]` | Anthony Williams, **C++ Concurrency in Action**, 2nd ed. (2019). |

## How to use this list

You will not read all of these. The roadmap tells you which **sections**
to read, unit by unit, and that adds up to perhaps 15–20% of the pages
here. Buying every book on this list up front is a way of feeling
productive without being productive.

If you buy exactly three: `[GEA3]`, `[RTCD]`, `[RTR4]`. If you buy zero,
`[GPP]`, `[3DMP]`, `[PBRT]`, `[DOD]`, `[LEARNOGL]`, `[SCRATCH]`,
`[GAFFER]`, and `[GAMEAIPRO]` are free and cover a genuinely large
fraction of the track.
